# Gleam v1.35.0 security audit

## Scope

Diff: `3d2136a..12b4b52`. Security-surface files changed: three, listed below.

Surface paths changed:

- `packages/runtime/src/handlers/points.ts`: `scores()` clears the local memberships and the registered flag when `POST /me` answers 404, then returns `null`. It writes only local state, on an answer from the Gleam server over TLS, and the device re-registers on the next join. It signs nothing new and sends nothing new.
- `packages/messaging/src/protocol.ts`: `getTokenPrices` takes an optional `processIds`. The method stays wallet-owner-only (`EXTENSION` tier in `dispatch/methods.ts`), so no page can send it.
- `packages/*/package.json`, `apps/*/package.json`, `pnpm-lock.yaml`: patch and minor bumps merged from Dependabot (#119, #120): `@webext-core/messaging` 4.0.1, `wxt` 0.21.5, `vite` 8.3.5, `hono` 4.13.14, `@tanstack/react-query` 5.104.5, `typescript-eslint` 8.72.0, `@dha-team/arbundles` 1.1.0 (a dev dependency of `core`, bundled into the extension), `@electric-sql/pglite` 0.5.11. No new package, no new install script.

Other changes since v1.34.0, outside the surface:

- `packages/core/src/pricing/best-ask.ts`, `snapshots.ts`, `packages/runtime/src/handlers/reads.ts`: tokens outside the registry get a spot price from their own orderbook (the lowest open ask, in AR, at AR's price). The read goes only to the node the user already uses for balances, so no new host. A process id must be 43 characters of base64url and not a registered token; at most 50 per request; nothing is matched by ticker; discovered tokens are never priced. Node responses are untrusted: amounts must be unsigned integers, an order's key must equal its `order-id`, a lot under 0.1 AR can't set a price, and more than 150 orders gives no price. Any failure shows no price. Nothing a signature depends on reads a price. Samples are kept in `local:priceSnapshots`, keyed by process id, pruned to 30 hours.
- `packages/app/.../MainScreenView.tsx`, `useTokenPrices.ts`: rows show the price, and the chart total adds the priced tokens' current value. No new message type.
- `packages/core/src/ao/asset-scan.ts`, `collectibles.ts`, `token-discovery.ts`: discovery scans share one aliased GraphQL query per page, and a failed descriptor batch no longer discards the rest. Same gateway, same data.
- `apps/site/*.html`, `FoundingGate.tsx`: the invite ask on X opens with `@gleam_wallet #GleamInvite`. A fixed link, no data sent.
- Versions: 1.35.0, with build numbers incremented.

Run:

- `pnpm vitest run` (3583 passed), tsc on all eleven projects, eslint on changed files, `pnpm wxt:build`, `pnpm mobile:build`, `pnpm audit --prod`.
